# OSMAN — финансовая панель (открытая версия)

Отдельное приложение с шестью вкладками финансового директора. **Без логина и пароля**: открыл ссылку — сразу видишь данные.

| Вкладка | Маршрут |
|---|---|
| P&L (foyda va zarar) | `/finance/pnl` |
| P&L — batafsil | `/finance/pnl/detail` |
| BEP va Sensitivity | `/finance/pnl/bep` |
| Cashflow | `/finance/cashflow` |
| Balans va koeffitsiyentlar | `/finance/balance` |
| Byudjet (Plan/Fakt) | `/finance/budget` |

Корень `/` и любой неизвестный адрес открывают P&L.

## Чем отличается от основного репозитория

Код взят из `osman-finance-dashboard` (ветка `stage-3`) и урезан: страницы, графики, расчёты и переводы — те же.

Убрано: вход и роли (`src/auth`), серверный API (`server/`, `src/lib/api`), админ-панель и импорт Excel, разделы закупок, склада, продаж, «Общий обзор» и панели владельца.

Осталось всё, что нужно шести вкладкам: период (QTD/YTD/свой период, сравнение с прошлым периодом, прошлым годом или планом), валюта UZS/USD, темы, три языка (uz/ru/en), экспорт таблиц и графиков в Excel, печать в PDF, поиск по ⌘K.

## Данные

Данные живут **в браузере**: детерминированный демо-набор на 24 месяца (`src/data/seed.ts`, текущий период `2026-08`), сохраняется в `localStorage`. Сервера нет — значит, нечего взламывать и нечему падать. «Демо ma'lumotni tiklash» на пустом экране возвращает набор обратно.

Чтобы показать реальные цифры, замените генератор в `src/data/seed.ts` (формат — `Dataset` из `src/types/index.ts`). Всё, что попадёт в сборку, видно любому, у кого есть ссылка: не кладите сюда то, что не готовы показывать публично.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5175
```

Порт 5175 занят намеренно: 5173 — другой проект владельца, 5174 — основной OSMAN dashboard.

## Проверки

```bash
npm run typecheck
npm test
npm run check:palette   # контраст и различимость палитры
npm run build
```

## Деплой

Статический сайт: `npm run build` → `dist`, раздача через `npm run start` (`serve -s dist`). `railway.json` уже настроен под Railway (NIXPACKS). Переменные окружения не нужны, база и API — тоже.
